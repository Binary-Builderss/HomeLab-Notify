Privacy policy

Homelab Notify for iPhone and iPad. Last updated 20 October 2026.

Homelab Notify does not collect any data. The developer (BinaryBuilders) receives nothing from the app: there is no account, no analytics, no crash reporting, no advertising and no third-party SDK.

The app connects only to the Homelab Notify server that you install on your own machine and pair with the app. What it shows (incidents, containers, rules, host status) comes from that server and is sent back only to it, for example when you acknowledge an incident or change a rule. That server is operated by you, not by us.

On the device the app stores the paired server address, the device token issued by your server (in the iOS Keychain) and a copy of the last data it loaded, so it stays readable offline. Unpairing the device in the app removes them. Revoking the device from your server's dashboard makes its token useless at any time, even if the app was deleted.

The demo mode uses built-in sample data and makes no network connections.

Questions: contactus@binarybuilders.dev.

Informativa sulla privacy

Homelab Notify per iPhone e iPad. Ultimo aggiornamento 20 ottobre 2026.

Homelab Notify non raccoglie alcun dato. Lo sviluppatore (BinaryBuilders) non riceve nulla dall'app: nessun account, nessuna statistica d'uso, nessuna segnalazione di crash, nessuna pubblicità e nessun SDK di terze parti.

L'app si collega solo al server Homelab Notify che installi sulla tua macchina e abbini all'app. Quello che mostra (incidenti, container, regole, stato dell'host) arriva da quel server e viene rimandato solo a lui, per esempio quando prendi in carico un incidente o modifichi una regola. Quel server lo gestisci tu, non noi.

Sul dispositivo l'app conserva l'indirizzo del server abbinato, il token rilasciato dal tuo server (nel Portachiavi di iOS) e una copia degli ultimi dati caricati, per leggerli anche offline. Disabbinare il dispositivo dall'app li cancella. Revocare il dispositivo dalla dashboard del tuo server rende inutilizzabile il suo token in qualsiasi momento, anche se l'app è stata eliminata.

La modalità demo usa dati di esempio inclusi nell'app e non fa connessioni di rete.
